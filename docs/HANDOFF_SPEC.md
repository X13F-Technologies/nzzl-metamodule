# NZZL — MetaModule Plugin: Claude Code Handoff

## Context

We are building a custom native MetaModule plugin called **NZZL** — a deterministic generative bassline/sequencer module. It will be built using the 4ms MetaModule Plugin SDK as a native plugin (not a VCV Rack port), compiled for ARM via GitHub Actions CI, and deployed to a 4ms MetaModule hardware module via SD card.

The module is inspired by Sting 2 (Max for Live) and the Turing Machine, but with a distinct design philosophy: all output is deterministic from a seed. There is no runtime randomness during playback.

---

## Phase 2: Module Specification

### Module Identity

- **Name:** NZZL
- **Slug:** NZZL
- **Type:** Native MetaModule CoreProcessor plugin
- **Panel width:** ~16HP (flexible, similar to Turing Machine)

---

### Jacks

#### Inputs
| Jack | Description |
|---|---|
| CLOCK | Clock input — advances sequencer one step per pulse |
| RUN | Gate high = sequencer runs, Gate low = sequencer holds position (does not reset) |
| RESEED | Trigger input — fires a new random seed, updates group/subgroup knob positions to reflect |
| CV SCALE | CV override for scale selection |
| CV SEED | CV offset for seed selection |
| CV ROOT | CV override for root note |
| CV SLIDE | CV amount added to slide (summed with seed-derived slide, scaled by attenuator knob) |

#### Outputs
| Jack | Description |
|---|---|
| CV PITCH | V/Oct pitch output (1V/octave standard) |
| GATE | Gate output — high when step is active |
| VELOCITY | 0–10V velocity/accent output — seed-derived per step |

---

### Knobs

| Knob | Range | Description |
|---|---|---|
| GROUP | 1–32 | Selects seed group. Zones: 1–10 = Bassline, 11–21 = Random, 22–32 = Arp |
| SUBGROUP | 1–32 | Selects seed within group. In Arp zone: 1–8 = Ascending, 9–16 = Descending, 17–24 = Up-Down, 25–32 = Down-Up |
| DENSITY | 1–16 | Deterministic step threshold — see logic below |
| LENGTH | 2–16 | Number of active steps in sequence |
| CLOCK DIV | 1–16 | Divides incoming clock (÷1 through ÷16) |
| OCTAVE RANGE | 1–5 | How many octaves the sequence spans |
| ROOT | C through B (12 values) | Root note of the scale |
| SCALE | 12 scales | See scale list below |
| SCALE LOCK | On/Off toggle | When off, pitch output is raw 0–5V (no quantization) |
| SLIDE | 0.0–1.0 attenuator | CCW = no slide regardless of seed. CW = full seed-derived slide amount |

---

### Seed System

**Total seeds:** 32 (groups) × 32 (subgroups) = 1024 unique seeds

**Seed index calculation:**
```
seed_index = (group - 1) * 32 + (subgroup - 1)  // 0–1023
```

**Group zones:**
- Groups 1–10: Bassline style seeds
- Groups 11–21: Random style seeds  
- Groups 22–32: Arp style seeds

**Within Arp zone, subgroup zones:**
- Subgroup 1–8: Ascending arp
- Subgroup 9–16: Descending arp
- Subgroup 17–24: Up-Down arp
- Subgroup 25–32: Down-Up arp

**Seed derivation:**
Use a deterministic RNG (xorshift32 or similar) seeded with `seed_index`. From this generate all per-step values at pattern initialization:
- Step activity weight (1–16)
- Step pitch index (into scale)
- Step gate length (fraction of clock period)
- Step velocity (0.0–1.0)
- Step slide flag (boolean, weighted by style)
- Step octave offset (0 to octave_range-1)

**Reseed trigger behavior:**
When RESEED jack receives a trigger pulse:
1. Pick a new random seed_index (using a separate non-deterministic source for this one moment)
2. Regenerate all step values from that seed
3. Update GROUP and SUBGROUP knob positions to reflect the new seed_index location

**Patch save:**
Current seed_index (and therefore group/subgroup positions) must be saved with the MetaModule patch state.

---

### Density Logic

Each step has a `weight` value (1–16) generated deterministically from the seed at initialization.

```cpp
step_is_active = (step.weight <= density_knob_value)
```

- Density 1: only the lowest-weight step plays
- Density 16: all steps play
- Same seed + same density = always identical output
- Changing density and returning to previous value = identical output restored
- No probability, no randomness at playback time

---

### Style Behavior

Style is determined by the GROUP zone, not a separate knob.

**Bassline style (groups 1–10):**
- Pitch weighting: heavy bias toward root (degree 0) and 5th (degree 4 in Dorian/minor)
- Octave jumps: rare (low probability in seed generation)
- Repetition: high — many steps share the same pitch
- Rhythm weighting: notes cluster on beats 1 and 3, sparse off-beat
- Gate length: mostly short (staccato feel)

**Random style (groups 11–21):**
- Pitch weighting: even distribution across all scale degrees
- Octave jumps: moderate probability
- Repetition: low — pitches spread across range
- Rhythm weighting: even across all steps
- Gate length: varied

**Arp style (groups 22–32):**
- Pitches sorted into ascending, descending, up-down, or down-up order based on subgroup zone
- Pitch weighting: spread evenly but ordered on playback
- Rhythm: even subdivisions
- Gate length: consistent (arp feel)

---

### Rhythm Behavior

- All active steps land on even clock subdivisions — no swing or syncopation
- The seed determines **which** steps are active, not timing within a step
- Gate length per step is seed-derived (short, medium, long) — expressed as a fraction of the clock period

---

### Slide / Portamento

- Each step has a seed-derived slide flag (boolean)
- When a step has slide: CV output glides from previous pitch to current pitch over a time period
- Slide time is constant (derived from clock tempo feel)
- SLIDE attenuator knob scales the glide amount: CCW = instantaneous (no slide), CW = full seed-derived slide
- CV SLIDE jack adds to slide amount (summed before attenuator scaling)

---

### Pitch / Scale System

**When scale lock ON:**
Output pitch = root + scale_degree + octave_offset, quantized to selected scale, expressed as V/Oct

**When scale lock OFF:**
Output pitch = raw seed-derived value mapped to 0–5V range (no quantization)

**Root note:** C through B, set by ROOT knob or CV ROOT jack

**Available scales (12):**
1. Major (Ionian)
2. Natural Minor (Aeolian)
3. Dorian
4. Phrygian
5. Mixolydian
6. Lydian
7. Harmonic Minor
8. Melodic Minor
9. Pentatonic Major
10. Pentatonic Minor
11. Chromatic
12. Whole Tone

Store as semitone interval arrays, e.g.:
```cpp
const int SCALE_DORIAN[] = {0, 2, 3, 5, 7, 9, 10};  // 7 degrees
```

---

### Run Input Behavior

- Gate HIGH → sequencer advances on each clock pulse
- Gate LOW → sequencer freezes at current step position
- Does NOT reset to step 1 on transition — holds position
- If RUN jack unpatched, sequencer runs freely

---

### Display

Use whatever text display capability the MetaModule SDK natively supports (TextDisplay or equivalent from CoreProcessor API).

Show:
- Current style zone: `BASS`, `RAND`, `ARP↑`, `ARP↓`, `ARP↕`, `ARP↔`
- Current group and subgroup: e.g., `4 . 7`
- When reseed fires: brief flash or indicator

## Phase 3: Implementation Order

Build and test in this order to keep iteration fast:

1. Project scaffolding + CI pipeline working (produces a valid `.mmplugin`, even if empty)
2. Clock + Run input — sequencer steps on clock, freezes on Run low
3. Seed system — RNG, step data generation, group/subgroup knob mapping
4. Density logic — deterministic step activation
5. Pitch output — scale quantization, root, octave
6. Gate output
7. Velocity output
8. Scale lock toggle
9. Slide / portamento
10. Style differentiation (bassline vs random weighting)
11. Arp mode ordering
12. Reseed trigger + knob update
13. Display output
14. CV inputs for all CV-controllable parameters
15. Patch state save

## Notes

- The ARM toolchain version must be exactly 12.2 or 12.3 — not newer
- Build produces a `.mmplugin` file dropped onto SD card under `metamodule-plugins/` folder
- Patch state (including current seed_index) should use whatever state persistence the CoreProcessor API provides
- All playback logic must be deterministic — no `rand()` or non-seeded random calls during the process loop
- The only non-deterministic moment is when the RESEED trigger fires
